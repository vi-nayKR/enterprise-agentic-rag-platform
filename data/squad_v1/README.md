# Approved SQuAD corpus

Source: [Stanford Question Answering Dataset](https://rajpurkar.github.io/SQuAD-explorer/),
the publicly released SQuAD 1.1 development set. Questions and answer spans were
written by the original human annotators, not generated by this project. Rows
record `synthetic: false` and `origin: human_authored_squad`.

The dataset is distributed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
Attribution: Pranav Rajpurkar, Jian Zhang, Konstantin Lopyrev, and Percy Liang,
*SQuAD: 100,000+ Questions for Machine Comprehension of Text* (2016).
Wikipedia passage authors retain their attribution; each corpus record preserves
the article title. This selected, reformatted subset remains CC BY-SA 4.0.
This dataset notice does not license the repository's application code.

Reproduce with `python scripts/prepare_squad.py`. The source download's SHA-256,
selection seed, and generated counts are recorded in `results/dataset_v1.json`.
The cached upstream file is excluded from Git; retain the recorded hash when
checking a new download. Version a changed source or sampling procedure separately.

The script selects questions from distinct paragraphs across named science and
technology articles. Dev and test articles are disjoint. Retrieval candidates
include every available paragraph from all selected articles, not just the gold
passages. Gold answers and splits are not inputs to the answering model.
`source_chunk_id` identifies the original paragraph; later chunking experiments
must preserve source offsets and map answer spans onto their generated chunks.

## Your test review

Edit `test_review.jsonl` before accepting held-out answer results. Read each
question and `source_text`, check every answer's meaning and character offset,
and set `reviewed: true` with your name in `reviewer`. Record any corrections
in `corrected_answers` (the same text/answer_start schema), and explain them in
`notes`. Leave `corrected_answers` null when the original annotations stand.
Regenerating the dataset never overwrites this review file. The agent must not
mark cases reviewed on your behalf.

## Limits

This is a small, single-hop, extractive Wikipedia benchmark, not evidence of
enterprise-document, multi-hop, or production quality. Original source labels
are not exhaustive relevance judgements across all corpus passages. The original
SQuAD dev data is public and may be present in model training; this project's
held-out split is not an unseen-model-pretraining guarantee. Select configurations
on dev only, then report test performance without tuning on it. Embedding
fine-tuning must use separate upstream training articles, not this dev/test data.
